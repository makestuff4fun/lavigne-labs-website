To Watch

A personal film and TV tracker for one person. It runs inside a private Android app on the owner's own phone. Nobody else has access, and nothing is published or sold.

What it is
A watch list: search films and TV, see what is coming out, save titles to a list
Users
One (the developer); no public sign-up, no app-store listing
Platform
Native Android app, privately installed, plus a private home server
Money
None: no ads, no subscriptions, no paid features, no data sales
Status
In development; the list feature comes first

What it does

  • Search all of film and television history by title or person.
  • Show a title page with its poster, overview, cast, release date and seasons.
  • Browse upcoming releases and new seasons of shows already on the list.
  • Keep a personal list: why a title was added, who recommended it, whether it has been watched, and a rating afterwards.

How TMDB data is used

The phone never calls TMDB directly. The app talks only to the owner's private server, which makes the TMDB requests and passes the results back.

Android app → private server (holds the API key) → TMDB API
  • The API key stays on the server and never ships inside the app.
  • Requests are made only when the owner searches or opens a title, so traffic is a handful of calls a day.
  • Responses are cached briefly to avoid repeat calls, and refreshed rather than kept as a copy of the database.
  • Posters and images load from TMDB's image service as provided.
  • No TMDB data is redistributed, resold, or shown to anyone other than the owner.

Attribution

The app's About screen shows the TMDB logo and the required notice, and title pages credit TMDB as the source of their data.
