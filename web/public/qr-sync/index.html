QR Time Sync

Displays a QR code encoding the current time in milliseconds, refreshed every display frame. Film this screen with each camera, then decode the footage to align all recordings on one clock.

How to use
  1. Set screen brightness to maximum and disable auto-brightness.
  2. Tap Start — the screen stays awake while running.
  3. With every camera already recording, hold this screen in front of each lens for 3–5 seconds, close enough that the code is sharp.
  4. Repeat at the end of the session to measure clock drift.
  5. Run the decoder script (Python + OpenCV) on the footage to get frame → time mappings.
